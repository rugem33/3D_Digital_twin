# 전체 논문 흐름 및 일관성 교정 기록

대상: `졸업논문_학과양식반영_수정초안_20261115.hwp`와 편집용 DOCX.
최신 결과: `졸업논문_전체흐름교정본_20261115.hwp`.

## 교정 원칙과 보존 확인

- 논문의 연구 범위와 정보를 요약·축소하지 않고, 문단 단위로 용어·연결·시제를 다듬었다. 원본 파일은 보존했다.
- 기존 문단 텍스트는 17,858자에서 20,270자로 늘었다. 이 수치는 표지·목차·참고문헌을 포함하는 문단 텍스트이며 표 셀과 그림 속 문자는 제외한다.
- 원본의 작성·실측·그림 삽입 표시 51개를 문구별 개수로 대조하여 모두 유지했다. 추가 확인 항목은 별도로 보강했다.
- 표 6개와 그림 2개를 유지했다. 표의 경로 판정과 자료 제외 내역을 보강하고, 그림 2는 현재 처리 분기에 맞춰 수정했다.
- 학과 양식의 11pt·160%와 여백·표지 형식을 유지했다. 표 열 너비를 조정하여 넘침을 해결했으며 본문을 줄이거나 글꼴을 축소하지 않았다.

## 코드 대조에서 확인한 중요한 수정

1. `dem_clamp_worker.py`는 SHP를 조회 가능 범위로 절단하고 NoData 객체를 제외한 사본으로 변환한다. 모든 누락을 전체 실패로 설명했던 문장과 그림을 수정했다. 교집합·유효 객체가 없거나 다른 검증 오류가 있으면 실패한다.
2. `ShpTo3dTile.cs`는 표시 중인 지형 작업 ID가 있으면 우선 사용한다. 서버는 완료 작업의 원본 DEM으로 전처리하고 동일 작업의 `layer.json`을 Mago에 전달한다. 직접 DEM 업로드 경로는 전처리 GeoTIFF를 참조한다. 두 입력은 동시에 허용되지 않는다.
3. `config.py`의 현재 Mago 기본 설정은 1.16.3이다. 과거 1.15.4의 7개 검사 통과 기록을 현재 버전의 결과로 간주하지 않도록 본문과 참고문헌을 수정했다. 이번 교정에서는 소프트웨어 테스트를 재실행하지 않았다.
4. 실험 눈높이는 사용자 확정 2m를 유지한다. 현재 코드 기본값 2m와 장면 저장값 3m의 차이를 명시하여 실험 빌드 설정 확인 항목에 연결했다.
5. 높이 입력은 DBF 열 또는 고정 숫자이다. 현재 장면의 `heightColumn: 12`는 고정 높이 입력이며 실제 높이 속성 열과 다르다. 현재 장면의 skirt 저장값은 0이다. 논문에는 실험의 실제 적용값을 별도 기록하도록 하였다.
6. NavMesh 부분 경로 뒤에 목적지 연결 직선이 붙는 경우를 유효 완전 경로·전체 직선 대체와 분리했다. 도착 이벤트는 수평 반경 판정이며 경로 유효성·출입구 도달과 동일하지 않음을 명시했다.
7. 높이 조회 실패 시 캐시가 있으면 캐시를, 없으면 원시 GPS 변환 높이를 쓰는 대체 동작을 명시했다. 정상 상태만을 모든 실행 상태로 일반화하지 않도록 하였다.

## 검증 결과

- 실제 한글에서 HWP 저장 후 PDF로 렌더링했다. HWP 파일 시그니처를 확인했다.
- 전체 25쪽: 표지·내표지 2쪽, 목차·표/그림목차 2쪽, 본문 20쪽, 참고문헌 1쪽.
- 본문 20개 절의 실제 페이지와 목차, 표 6개·그림 2개의 캡션 페이지를 대조했다.
- 본문의 인용 번호 [1]~[8]과 참고문헌 대응을 확인했다. 새 외부 연구 결과를 도입하지 않았다.
- 전체 페이지 축소판과 표·그림·결론 등 주요 페이지를 이미지로 검토했다. 원본 파일 해시와 삽입 표시 보존 검사를 통과했다.
- 상세 변경 전후 문장은 `_work/polish_audit.json`, 검증 요약은 `_work/polish_validation.json`에 남겼다.

## 남은 입력 자료

실험 배포 버전과 빌드·장면 설정, 원자료 상세 출처와 수직 기준, 구역 A/B와 절단·제외 결과, 실제 단말·참여자 평가, 인적사항 및 제출 연월은 아직 확정·입력할 항목이다. 미측정 효과를 성과로 작성하지 않았다. 실제 실험 버전이 현재 코드와 다르면 해당 버전에 맞춰 구현 설명과 그림을 다시 고정해야 한다.

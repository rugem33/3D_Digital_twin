조사일: 2026-11-16. 대상은 최근 논문 보완 작업이 아니라 2026년 4~6월 원래 프로젝트 개발 기록이다. 로컬 Git의 전체 참조와 원본 Product/Sprint Backlog를 조사했다. 원격 저장소를 새로 가져오거나 당시 앱을 재실행하지는 않았다.

## 1. 결론과 기록 범위

**4~5월의 문제 기록과 수정 이력이 존재한다.** 기존 조사에서는 현재 남아 있는 실행 로그와 최근 DEM 검사에 치우쳐, Git에서 삭제된 당시 문서와 과거 코드 변경을 충분히 반영하지 못했다. 아래 기록으로 그 범위를 보완한다.

- Git의 4~6월 기간 조회에서는 4월 10일~5월 22일 커밋이 확인된다. 현재 로컬 참조에서 6월 커밋은 조회되지 않았다. 외부 저장소·다른 PC·별도 대화 기록에도 없다는 뜻은 아니다.
- `Docs/session_terrain_vworld.md`는 문서 안에 작성일 5월 14일이 있고, 5월 15일 커밋 `a005dd1`에 포함됐다. 5월 22일 `45c57fc`의 디렉토리 정리에서 삭제됐지만 부모 버전에서 복원할 수 있다.
- Git에 같은 내용의 재작성·병합 이력이 있으므로 유사 커밋을 독립 오류나 반복 실험으로 중복 집계하지 않는다.
- 아래 날짜는 문서 내부 날짜 또는 커밋 날짜다. 별도 실행 증거가 없는 경우 정확한 오류 발생일·현장 시험일로 단정하지 않는다.

## 4. 논문에 반영할 수 있는 내용

1. 개발 과정의 문제·대응 사례: 시설물 높이 이격, GPS·비동기 높이 조회 안정화, 지형 타일 좌표 계산 수정, 낮은 상세도 타일 우회, 지도 이미지 전환, DBF 인코딩 처리.
2. 기능 정상 동작의 근거: 당시 Sprint DoD의 확인 서술과 현재 사용자의 정상 동작 확인을 시점·빌드 범위를 구분하여 기록한다.
3. 개선 효과의 수치: 위 기록만으로 성공률·오차 감소율·크래시 감소율을 만들지 않는다. 원시 측정이 없으면 정성적 수정 사례로 작성한다.
4. 오류 버전과 실험 버전: 기존 `app_beta*`·커밋을 논문의 A(0.1.0), A-1(0.1.1)로 자동 치환하지 않는다. 논문의 첫 시험과 수정 순서를 확인해 대응시킨다.

기존 `개발오류_및_기능확인_기록_20261116.md`는 Mago 실행 로그·현재 확인 상태를 다루는 별도 기록이다. 그 파일의 ‘실제 단말 발생 로그 미확보’는 과거 작업 문서나 수정 커밋도 없다는 뜻이 아니며, 본 조사에서 확보한 문서 근거를 함께 사용한다. 날짜가 없는 현존 Mago 로그는 파일 존재만으로 4~6월 실행이라고 소급하지 않는다.

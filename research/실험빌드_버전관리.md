# 실험 빌드 버전 관리

## 논문 실험의 시작 기준

- **논문에서 처음 테스트하는 빌드**를 **실험 빌드 A(0.1.0)**로 지정한다.
- 버전 번호는 논문에서 실제 시험·수정한 흐름을 따라 부여한다. 현재 로컬 상태나 최신 커밋을 자동으로 첫 실험 버전으로 지정하지 않는다.
- 최초 시험에 사용한 코드·빌드·설정과 확인 기록을 A에 연결한다. 실제 시험 자료가 정리되기 전에는 구체적인 커밋이나 설정을 임의로 확정하지 않는다.
- [로컬 버전 확인 기록](로컬버전_확인기록_20261115.json)은 현재 소스의 참고 기록이며 A의 시험 상태를 입증하는 기록과 구분한다.

## 부분 수정 규칙

| 명칭 | 버전 | 의미 |
|---|---|---|
| 실험 빌드 A | 0.1.0 | 논문에서 처음 테스트하는 빌드 |
| 실험 빌드 A-1 | 0.1.1 | 최초 시험 이후 첫 부분 수정·시험 빌드 |
| 실험 빌드 A-2 | 0.1.2 | 다음 부분 수정·시험 빌드 |
| 실험 빌드 A-3 | 0.1.3 | 이후 부분 수정·시험 빌드 |

부분 수정마다 변경 이유, 코드·설정·자료 변경 내용, 시험 조건과 결과를 기록하고 사용한 빌드·커밋 또는 파일 해시를 대응시킨다. 각 실험 버전의 기록은 보존한다. 같은 상태에서 실험을 반복하는 경우에는 버전을 올리지 않고 측정 회차로 구분한다. 버전별 결과를 작성할 때 실제로 수행하지 않은 시험이나 개선 효과를 만들어 넣지 않는다.

논문·실험 로그·이미지·차트에는 `실험 빌드 A(0.1.0)`처럼 병기한다. 실제로 A-1을 사용했다면 A와 구분하여 기록한다. 논문 문장만 교정한 경우에는 앱 실험 버전을 올리지 않는다.
